Что забрать с собой

Все файлы открываются в браузере, в том числе на телефоне. Откройте файл, выделите весь текст, скопируйте и вставьте в чат с нейросетью. На страницах блоков 5, 6 и 7 и в шкатулке те же тексты есть с кнопкой «Скопировать текст».

Готовые запросы (классическая психодрама)
  • Запрос для разбора. ПолныйДвенадцать правил точности, шесть психодраматических паттернов и структура ответа. Для индивидуальной сессии. Подробно в блоке 6.
  • Запросы Б. Девять дополнительных блоковСоциальный атом, ролевой репертуар, полярности, обобщения, первая сцена, спонтанность, незавершённое, сцена встречи, сцена, если она была. По одному за раз, в том же чате.
  • Запрос В. СамопроверкаОбязательный последний шаг: модель ищет в своём ответе утверждения без цитаты, склеенные цитаты, перепутанных говорящих. Подробно в блоке 5.
Парная схема (клиническая психодрама)
  • Запросы А, Б, В для клинической психодрамыМентализация по четырём функциям, модус, Я-состояния, защиты, работа со стульями, дублирование. Наблюдения, а не диагноз: определять уровень организации личности в запросе запрещено, и этот запрет надо оставлять.
Материал для пробы
  • Учебный фрагмент сессииСконструирован по мотивам учебных сессий и практики, все детали изменены. Примерно 12 минут разговора, Р1 клиентка, Р2 терапевт, с таймкодами. На нём можно повторить разбор по запросу из блока 6.
  • Пример готового ответа моделиНастоящий ответ на запрос для разбора по учебному фрагменту, как есть, без правок. Для тех, у кого нет доступа к нейросети, и для сравнения со своим результатом. В нём есть неточности, они разобраны в блоке 6.
Этика и данные
  • Шкатулка запросов для записей сессийГотовые запросы: SOAP, DAP, BIRP, GIRP, PIRP, STIPS, процессуальная запись, отчёт для супервизии, записка клиенту, приёмная записка, поминутное содержание, динамика по нескольким сессиям, запрос по своей структуре. Там же психодраматическая добавка, конструктор добавки под свой подход и две линзы.
  • Памятка по этике и данным, одна страницаВосемь шагов блока 3: закон, согласие, запись, расшифровка, обезличивание, что происходит с текстом в нейросети, хранение, ответственность. Можно распечатать или сохранить в PDF с телефона.
Для тех, кто хочет дальше
  • Простой путь: без агентов и настроекПошагово для ChatGPT и DeepSeek, подойдёт и для других нейросетей. Запрос для разбора одним сообщением и две проверки файлами.
  • Я в этом не разбираюсь: как я работаю с агентомЧем агент отличается от чата, мои настоящие запросы и первый запрос, который можно взять.
  • Кто такой Левенчук и что такое FPFЧьи принципы лежат в основе фреймворка и где их взять.
  • Вопросы после мастерскойЗадать вопрос письменно и посмотреть ответы на вопросы других.
  • Как предложить правкуЧто нужно, чего присылать нельзя, как написать на GitHub или забрать слайдомент себе.
  • Соберите свою систему разбора с нуляПуть с пустой папки: шаблон правил для ИИ, пробные разборы за один вечер, две проверки с готовыми текстами, что получилось у меня в цифрах.
  • Фреймворк: разбор записи монодраматической сессии с ИИЧерновик, который можно взять и доработать под себя: правила точности, шесть паттернов, словарь ходов терапевта со ссылками на книги.
  • Пример LPF: как устроено у меняМоя местная практика записи сессий: путь одной сессии, три проверки, журнал ошибок. Без клиентских текстов.

Как пользоваться, коротко
  1. Взять расшифровку сессии, убрать имена и всё, по чему человека можно узнать.
  2. Вставить запрос для разбора, ниже текст сессии.
  3. Прочитать и проверить цитаты. Всё без цитаты это слова модели, а не факт встречи.
  4. Дальше добавлять блоки из запроса Б, по одному сообщению.
  5. В конце обязательно прогнать запрос В.
