# ИИ не знает психодрамы. Научим?

Слайдомент мастерской Анастасии Феоктистовой на конференции по психодраме (ноябрь 2026).
Простые статичные страницы, без сборки. Текст правится прямо в html-файлах.

- `index.html` титульная страница и оглавление
- `01-razogrev.html` … `10-sharing.html` девять блоков программы (в именах файлов номера идут до 10, файла 08 нет)
- `zabrat.html` что забрать с собой, `istochniki.html` источники
- `files/` запросы, учебный фрагмент, пример ответа, памятка
- `style.css` оформление

Учебный фрагмент сессии полностью выдуман. Реальных клиентов в этом репозитории нет.

## Что ещё лежит рядом

- `prostoj-put.html` простой путь без агентов: ChatGPT, DeepSeek
- `agent.html` как автор работает с агентом, не разбираясь в технике, и Codex пошагово
- `sobrat-sistemu.html`, `dpf.html`, `primer-lpf.html` своя система с нуля, фреймворк, пример местной практики
- `levenchuk.html` кто такой Левенчук и что такое FPF
- `pravki.html` как предложить правку
- `framework/DPF-monodrama.md` фреймворк обычным текстом, его можно править карандашом прямо на GitHub

## Как предложить правку

Раздел Issues, кнопка New issue. Или карандаш в файле `framework/DPF-monodrama.md`.
Записи и расшифровки реальных сессий сюда не присылать, даже обезличенные.
